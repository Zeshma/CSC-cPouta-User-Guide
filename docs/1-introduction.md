# 1. Introduction

## 1.1 Purpose of this guide

This guide provides beginner friendly introduction to CSC’s cPouta cloud platform.  
By following these steps, you will learn how to:

- create a CSC account  
- create a project  
- generate SSH keys  
- configure security groups  
- launch a virtual machine  
- connect via SSH  
- install software  
- host a simple website  

## 1.2 Who is this guide for?

- OAMK students  
- OAMK staff  
- Anyone unfamiliar with Linux or cloud platforms  

## How to use this guide

- All commands are copy-paste-friendly.
- If copy-paste breaks, paste into Notepad or a plain-text editor first.
- Screenshots may differ slightly from the current CSC interface.
