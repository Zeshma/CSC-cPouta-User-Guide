# 3. Creating a New Project

You must create a CSC project before you can launch virtual machines in cPouta.

## 3.1 Create a project in MyCSC

1. Log in to **MyCSC** with your HAKA account
2. Go to **Projects → + New project**
    <p align="center">
    <img src="/images/picture3.png" alt="Screenshot of a project creation" class="guide-screenshot" />
    </p>
3. Fill in the required fields and choose **End date** for the project
    <p align="center">
    <img src="/images/picture4.png" alt="Screenshot of project creation details" class="guide-screenshot" />
    </p>
4. Select **cPouta** as your service
    <p align="center">
    <img src="/images/picture5.png" alt="Screenshot of project creation, services" class="guide-screenshot" />
    </p>
5. Choose a resource package
6. **Read and accept** the terms of use
7.	Once created, go to **Profile** and **+ Enable** CSC Multi-Factor Authentication. This is required to use cPouta. For more information: [https://docs.csc.fi/accounts/mfa/](https://docs.csc.fi/accounts/mfa/)
    <p align="center">
    <img src="/images/picture6.png" alt="Screenshot of CSC MFA enabling" class="guide-screenshot" />
    </p>
8.	The project will appear in **Projects** overview, and you can access the cPouta dashboard through **Services** → (cPouta) **Login** with your HAKA credentials.
    <p align="center">
    <img src="/images/picture7.png" alt="Screenshot of My CSC project overview" class="guide-screenshot" />
    </p>
You can add members to your project with either **+ Add members** or **Generate invitation link**.

---

## 3.2 Accessing the cPouta dashboard

Once your CSC account and project are created, you can access cPouta cloud management interface **by logging in with your Haka credentials**. You will now see the cPouta dashboard.
