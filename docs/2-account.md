# 2. Creating a CSC Account

## 2.1 Create a CSC user account

1. Go to https://my.csc.fi  
2. Select **Create account**  
3. Log in using your **HAKA** credentials  
4. Confirm your email and set your My CSC password (this is not used to login).
5. After your account is approved, log in again using HAKA credentials.
You will now see the MyCSC dashboard, which confirms the account is active.
